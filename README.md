# Netology-Course-Android-Development


# Установка Java, скачивание репозитория и компиляция кода на Linux
### выполнение всех команд в терминале (открытие терминала для ubuntu / ubuntu-подобных дистрибутивов linux ctrl + alt + t)

## Установка Java 

```bash
sudo apt update
sudo apt install openjdk-17-jdk-headless -y
```
# Скачать репозиторий 

```bash
git clone https://https://github.com/Beda3113/Netology-Course-Android-Development
```
### Перейдите в папку с репозиторием
```bash
cd Netology-Course-Android-Development
```

### Компиляция первого задания
```bash
javac M1HW1.java
```
### Запуск первого задания

```bash
java M1HW1
```

### Компиляция второго задания
```bash
javac M1HW2.java
```

### Запуск второго задания

```bash
java M1HW2 440000 330000
```


### Компиляция второго задания (с использованием ввода через Scanner)
```bash
javac M1HW2v2.java
```

### Запуск второго задания (с использованием ввода через Scanner)

```bash
java M1HW2v2
```
